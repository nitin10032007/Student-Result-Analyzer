# Student Result Analyzer

A Python-based application to analyze student academic performance using Tkinter, Pandas, and NumPy.

## Features

* Calculate total marks and percentages
* Analyze student results and grades
* Identify PASS and FAIL students
* Display PASS students in green and FAIL students in red
* Search and display student records
* Visualize student performance through charts
* Export analyzed results

## Technologies Used

* Python
* Tkinter
* Pandas
* NumPy
* Matplotlib

## Project Files

* `main.py` — Graphical user interface
* `analysis.py` — Result analysis and calculations
* `charts.py` — Data visualization
* CSV dataset — Student records

## How to Run

1. Install Python.
2. Install the required libraries:
   `pip install pandas numpy matplotlib`
3. Run the application:
   `python main.py`

## Project Purpose

This project demonstrates Python GUI development, data analysis, and visualization through a practical student result management application.
